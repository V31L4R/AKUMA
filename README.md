# AKUMA

AKUMA is a desktop application for generating synthetic datasets with configurable schemas and controlled data corruption.

## Status

(!) 22.07.2026  Work in progress.

## Planned MVP

- Desktop GUI (Current WIP - Navigation menu has been created)
- Configurable data fields
- Synthetic data generation
- Controlled generation of corrupted records
- CSV, JSON, and Parquet export
